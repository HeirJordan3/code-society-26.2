# Code Society 26.2

This repository is the central hub for students and staff in the Code Society 26.2 cohort.

Use it to find the weekly schedule, course expectations, certification information, assignments, resources, and one-on-one meeting links.

**Program dates:** August 31 – November 20, 2026  
**Days:** Monday–Friday, 9:00 AM – 5:00 PM  
**Duration:** 12 weeks (8 weeks instruction + 4 weeks externship)

## Start Here

1. Review the [current week's schedule](schedule/week-02.md) (Week 2).
2. Check topics being covered.
3. Complete required assignments and CertMaster work.
4. Review [certification expectations](certification/README.md).
5. Use [course resources](resources.md).
6. Use [one-on-one links](one-on-one-links.md) when needed.
