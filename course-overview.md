# Course Overview

[Back to Course Home](README.md)

Code Society 26.2 prepares learners for entry-level IT support roles and CompTIA A+ certification.

Students build practical skills for diagnosing and resolving common hardware, software, networking, and security issues while developing professional workplace habits.

## Program Details

| Detail | Information |
|---|---|
| Program dates | August 31 – November 20, 2026 |
| Days | Monday–Friday, 9:00 AM – 5:00 PM |
| Duration | 12 weeks |
| Structure | 8 weeks instruction + 4 weeks externship |

## Skill Areas

This program covers:

- Hardware
- Operating systems
- Networking
- Mobile devices
- Security
- Troubleshooting
- Ticketing systems
- Customer service
- Professional communication
- Technical documentation
- Escalation judgment

## CompTIA A+

Students prepare for CompTIA A+:

- Core 1 — 220-1201
- Core 2 — 220-1202

Exam milestones:

- Core 1 exam — September 23, 2026
- Core 2 exam — October 22, 2026

See [CompTIA A+](certification/comptia-a-plus.md) for preparation details.
